# Security and privacy

This is experimental hardware/software integration. Face authentication and presentation-attack detection (PAD) are not validated or enabled by this release. Detection scores are not identity probabilities. Keep an independently tested password login and recovery path; uncertainty must require the password.

Do not post passwords, recovery keys, tokens, private keys, biometric templates, face images or private conversations. This source release excludes those materials. Test images are generated synthetic fixtures; exported logs are technical, selected and sanitized.

Hardware shutdown is a technical contract: worker exit, light disarm, kernel STOP/CLOSE, root-session exit and a fresh complete idle check must agree. Unknown completion is a failure, never success. Administrative authorization does not replace evidence. Keep the OV7251 reset delay of at least 5 ms, the bounded illumination window and temperature safeguards.

Use GitHub's private vulnerability reporting if it is enabled; otherwise contact the repository owner without posting sensitive exploit details or personal data in a public issue.
